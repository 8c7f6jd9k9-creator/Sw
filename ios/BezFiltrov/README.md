# Без фильтров (iPadOS)

MVP первого этапа (M1 из roadmap): онбординг с возрастным гейтом, раздельное
согласие каждого игрока, границы по темам, режим «Откровенные вопросы»,
кнопки «Пауза»/«Завершить» и aftercare. Полная спецификация — PRD и
архитектура в документе «Без фильтров»:
https://claude.ai/code/artifact/8e4bd621-3be6-407d-87d1-ba42b2fc50ca

## Что уже работает (M1)

- Экраны 1–4, 6, 7 из карты экранов PRD: Welcome/18+ → создание сессии →
  игроки → согласие и границы (по кругу, приватно) → уровень → игра.
- Режим «Откровенные вопросы», 30 карточек (уровни 1–6, App Store-safe),
  отфильтрованных по согласию и границам через `ConsentServicing`.
- `PauseOverlay`, всегда видимый во время игры: «Пауза» полностью скрывает
  текущую карточку, «Завершить» ведёт на aftercare.
- Check-in каждые 4 карточки уровня ≥4 — «Да / сбавить темп / остановиться».
- Aftercare по кругу: «Как ты себя чувствуешь? / Что понравилось? / Что не
  повторять?», приватно для каждого игрока.
- Отзыв отдельного согласия (`revokeConsent`) немедленно убирает из колоды
  все карточки, которым это согласие требовалось, включая текущую.

## Чего нет в M1 (см. roadmap в PRD, §13)

«Правда или действие», «Совпадения», «Генератор сценариев», «Колесо
фантазий» и «Своя колода» смоделированы в `GameMode`, но не реализованы —
в выборе режима они видны, но неактивны. История сессий, adult web/PWA
сборка, локализация на другие языки и монетизация — v1.1+.

## Архитектура

Соответствует §9 PRD: `Models` (чистые value types) → `Data` (контент и
дизайн-токены) → `Services` (протоколы `ConsentServicing`/`DeckServicing`/
`PersistenceServicing`/`HapticsProviding` + их реализации) → `Stores`
(`SessionStore`, `@MainActor`, единственный источник состояния сессии) →
`Views`. Зависимости внедряются через `AppEnvironment`, собранный в
`BezFiltrovApp.init()` — глобальных изменяемых синглтонов нет.

`PersistenceService` — `actor`, обёртка над `UserDefaults`; ошибки
кодирования/декодирования не проглатываются, а прокидываются через `throws`
до `SessionStore.lastErrorMessage`, который показывает alert вместо тихого
падения на дефолтные данные.

Повторные быстрые нажатия «Дальше» гасятся в `SessionStore.requestAdvance()`
через отменяемый `Task` (debounce 120 мс) — вместо `DispatchQueue.main.asyncAfter`,
который не защищён от гонки при повторном вызове.

## Как открыть проект

Готового `.xcodeproj` нет — генерируется из `project.yml` через
[XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
cd ios/BezFiltrov
xcodegen generate
open BezFiltrov.xcodeproj
```

Таргет — только iPad (`TARGETED_DEVICE_FAMILY: "2"`), минимальная версия —
iOS 17.0. Если XcodeGen не хочется ставить — создайте в Xcode новый iPad App
проект (SwiftUI) с именем `BezFiltrov`, удалите сгенерированные по умолчанию
файлы и перетащите содержимое папки `BezFiltrov/` с опцией «Copy items if needed».

## Честно об ограничениях

Код написан и вручную проверен на баланс скобок и типовую согласованность,
но ни разу не компилировался — в этой среде нет macOS/Xcode toolchain.
Первый прогон в реальном Xcode может выявить мелкие ошибки типов или
неймспейсов; если такое случится, пришлите текст ошибки — поправлю.

Иконка приложения — заглушка (пустой слот 1024×1024 в `AppIcon.appiconset`),
перед публикацией в App Store нужна настоящая.
