# Дорога фантазий (iOS)

Полноценное SwiftUI-приложение для пары — карточная игра-разговор для дороги или дома. Развивает присланный прототип `FantasyRoadGameApp` в структурированное приложение с сохранением состояния, несколькими режимами игры и полноценной навигацией.

## Что нового по сравнению с прототипом

- **6 уровней по нарастающей, 300 карточек**: от тёплых вопросов для знакомства до уровня «Границы возможного» — по 50 карточек на уровень, включая лёгкие «карточки-действия» вперемешку с вопросами. Темы вроде фантазий о нескольких партнёрах или смене ролей раскрыты как честный, добровольный разговор о границах и согласии (в духе соседнего Python-приложения `questions.py` из этого репозитория) — без графичных описаний конкретных действий.
- **Честная раздача без быстрых повторов**: карточки уровня перемешиваются в колоду и раздаются по одной без повторов, пока колода не закончится («Карта 7 из 50 · Круг 2»), а не просто `randomElement()`.
- **Копилка сохраняется между запусками**: избранные карточки, статистика и настройки пишутся в `UserDefaults` через `Codable`, а не теряются при перезапуске.
- **Совместная игра по очереди**: включаемый режим «чей ход» с именами игроков, цветным бейджем и кнопкой «Поменяться».
- **Жесты и анимация**: свайп карточки вправо — в копилку, влево — пропустить; между карточками — анимация переворота.
- **Свои карточки**: отдельная колода «Свои карточки», куда можно добавлять собственные вопросы прямо в настройках.
- **Настройки**: имена игроков, вибрация (хаптика), тема оформления (системная/светлая/тёмная), сброс копилки и сброс прогресса.
- **Вступление с согласием**: экран онбординга подтверждает совершеннолетие и добровольность участия и напоминает, что за рулём картами управляет пассажир — карточку всегда можно пропустить без объяснений.
- **Поделиться карточкой** из копилки через системный шаринг.
- **Адаптивная раскладка**: боковая панель уровней на iPad/широких экранах, чипы уровней на iPhone — сохранено и улучшено из исходного кода.

## Структура проекта

```
FantasyRoadGame/
  FantasyRoadGameApp.swift      # точка входа
  Models/                       # GameCard, GameLevel, GameSettings, GameStats
  Data/                         # каталог карточек и цветовые темы уровней
  Services/                     # GameStore (состояние + персистентность), хаптика, шаринг
  Views/                        # экраны: игра, копилка, настройки, онбординг
  Resources/Assets.xcassets/    # AppIcon (заглушка) и AccentColor
project.yml                     # спецификация проекта для XcodeGen
```

## Как открыть проект

Готового `.xcodeproj` в репозитории нет — он генерируется из `project.yml` через [XcodeGen](https://github.com/yonaskolb/XcodeGen), чтобы не хранить хрупкий бинарный формат проекта в git.

1. Установите XcodeGen (один раз): `brew install xcodegen`
2. В этой папке выполните:
   ```bash
   cd ios/FantasyRoadGame
   xcodegen generate
   open FantasyRoadGame.xcodeproj
   ```
3. Выберите симулятор iPhone и нажмите Run.

Если не хотите ставить XcodeGen — создайте в Xcode новый проект **App** (SwiftUI, Swift) с именем `FantasyRoadGame`, удалите сгенерированные по умолчанию `ContentView.swift`/`*App.swift` и перетащите в него содержимое папки `FantasyRoadGame/` (Models, Data, Services, Views, Resources) с опцией «Copy items if needed».

Перед публикацией в App Store замените заглушку иконки в `Resources/Assets.xcassets/AppIcon.appiconset` на настоящую (1024×1024, без прозрачности).

## Ограничения и советы

- Минимальная версия iOS — 17.0 (используется `ContentUnavailableView`).
- Все тексты карточек — на русском языке; в `Data/GameContent.swift` их легко редактировать или расширять.
- Приложение не использует сеть и не собирает данные — всё хранится локально на устройстве через `UserDefaults`.
