# Промт для передачи в Claude — НормаКонтроль ОПО Windows 1.0 RC1

Ты продолжаешь разработку существующего приложения. Пользователь хочет один готовый Windows-продукт «НормаКонтроль ОПО»: реестр/документы ОПО, ЦАУК, ситуационные проверки, нормативная база знаний, локальная модель, локальные роли и возможность обучения. Архив NormaControl_OPO_Windows_1.0_RC1.zip прилагается. Сначала распакуй и изучи исходники, README_RU.md, docs/INTEGRATION_AUDIT_RU.md и docs/VALIDATION_WINDOWS_RC1.md. Сохрани существующий код и пользовательские данные. Не переписывай приложение с нуля и не создавай очередной демонстрационный сайт вместо Windows-программы.

Целевая машина по фото: Windows 10 Pro 22H2 x64, Intel Core i7-10700 2.90 GHz, 64 ГБ RAM, NVIDIA RTX A5000; версия драйвера на фото 597.06. Объём свободной VRAM ещё не измерен. Идентификаторы устройства/продукта не нужны и не передавай их.

Что передано:
- Нативный Tkinter + SQLite продукт; NormaControl.exe — Win64 launcher, вызывающий bundled runtime\pythonw.exe -I app_entry.py. Python 3.13.16 и Windows-библиотеки pypdf, pypdfium2, Pillow, ReportLab включены. Отдельный Python не требуется.
- app.py объединяет 8 вкладок: реестр, ЦАУК, база/OCR, нормативный каталог, обучение, агенты, ситуации, проверенные требования.
- core.py: 33 ОПО, документы, перечни, файлы, backup. inspections.py: 330 вопросов ЦАУК, доказательства/применимость.
- situations.py/situation_ui.py: ситуации, фото/документы, лексический подбор источников и проверенных требований с точными [Кsource-Фchunk], ручное решение/риск, аудит, PDF/HTML. Эвристический риск исходного веб-прототипа заменён оценкой специалиста. Демо-нормативы не импортированы.
- knowledge.py: извлечение TXT/DOCX/PDF/OCR, SQLite FTS5, реальные ссылки. Поиск лексический, не embeddings. DOCX без придуманных страниц; основной текст/таблицы, без колонтитулов/комментариев. Лимиты: 32 МБ, 150 страниц PDF, 2 млн символов. OCR требует внешний Tesseract с rus/eng.
- regulations.py и manifests: 46 карточек и 22 полных текста. 19 DOCX из предоставленного архива НД + прежняя копия №534 + два ТР ТС. Архивные документы пользователем разрешены для retrieval_authorized, но reviewed остаётся false. Даты редакций взяты из файлов, не подтверждены независимой правовой сверкой.
- Важное явное указание пользователя: приказ/ФНП №517 исключить. Не возвращай его в пакет/каталог. Старые связанные источники отключаются; произвольные самостоятельные пользовательские копии автоматически не выявляются.
- local_agents.py/agent_ui.py: Ollama только loopback 127.0.0.1:11434, запрет облачных моделей/внешних серверов, пять ролей, история. Роли дают текст, не выполняют модельные команды и не изменяют код. Документы не отправляются облаку. Модель qwen2.5:14b выбирается после отдельной установки (~9 ГБ); весов в архиве нет. 7B возможна при нехватке памяти. Не заменяй локальную архитектуру OpenAI/Claude API.
- training.py/train_lora.py/learning_ui.py: проверенные примеры, train/validation, блокировка пересечений/конфликтов, offline Hugging Face + PEFT LoRA q_proj/v_proj, heldout loss, адаптер и merged-модель, импорт в Ollama под новым именем. Для реального запуска нужны дополнительные torch/transformers/peft и локальные базовые веса. Само наличие кода обучения не означает обученную модель.

Данные: для новой установки %LOCALAPPDATA%\NormaControlOPO; при наличии старой базы %LOCALAPPDATA%\PromControlStage1 она используется без сброса. PROMCONTROL_DATA_DIR задаёт тестовую папку. Общая база promcontrol.sqlite3 + files входят в backup; большие модельные веса/результаты обучения вне backup. Перед миграцией/обновлением создать резервную копию. Изменение описания ситуации или добавление нового материала сбрасывает прежний риск/решение; история сохраняется.

Основа интеграции: ПромКонтроль v0.6 и исходники старого normkontrol-opo (FastAPI/React). Последний доступный архив REG-RU release 3b74969e — статическая сборка сайта без Windows backend; его CI в этой среде не перепроверен. Сайт не изменялся. Это Windows RC1 отдельного объединённого продукта, не подтверждение официальной «последней версии» коммерческого продукта.

Проверки выполнены: 65 unittest на Linux/Python3.12, все зелёные; реальные Tk-вкладки под Xvfb и сценарий save → источники → ручное решение → передача локальному агенту; 0 callback exceptions; новая база 68 источников/23044 фрагмента, 19 авторизованных НД, integrity_check ok, повторный seed без дублей. PDF проверен с кириллицей и настоящим изображением. Launcher собран MinGW PE32+ GUI x64; официальные runtime payload hashes и wheel SHA-256 зафиксированы.

НЕ проверено: запуск Win64 runtime/GUI на настоящем Windows; Wine заблокирован средой (socket Operation not permitted). Реальная генерация/скорость/GPU Ollama, LoRA с настоящими весами, русский OCR на Windows и юридическая актуальность документов. Не говори, что эти этапы прошли. Не обещай полную автоматическую проверку законодательства или промышленную готовность.

Твоя следующая задача:
1. На Windows выполнить Diagnostics_Windows.cmd и запустить NormaControl.exe. Если есть сбой — изучить %LOCALAPPDATA%\NormaControlOPO\logs и исправить именно текущую поставку.
2. Провести сценарии приёмки из docs/VALIDATION_WINDOWS_RC1.md. Проверить упаковку Tk/DLL/PDF, размер экрана/масштабирование, сохранение данных, backup и повторное открытие.
3. Установить Ollama/веса и проверить локальные ответы, ссылки, отсутствие внешней передачи, работу GPU и память на указанной машине.
4. Проверить основной сценарий на реальном документе/фото. Фото пока прикрепляется и включается в PDF; текстовая модель не выполняет анализ изображения автоматически. Для расширения явно выбирать локальную vision-модель и делать отдельные проверки качества.
5. Для обучения подобрать совместимую локальную базу по доступной памяти, подготовить проверенный датасет, выполнить небольшой реальный эксперимент и оценить ответы отдельно от loss. Не обучать на сырых документах как будто это готовые пары вопрос/ответ.
6. Довести найденные ошибки, обновить точный отчёт проверки, собрать новый Windows-архив и вернуть пользователю файлы и ясную инструкцию. Делай работу автономно в уже согласованном объёме; уточняй только отсутствующие обязательные данные.

Команды: runtime\python.exe -I app_entry.py --self-test; runtime\python.exe -m unittest discover -s tests -v (OCR-тест требует Tesseract eng). Исходник launcher windows_launcher.c; пересборка через MinGW: x86_64-w64-mingw32-gcc -municode -mwindows -static -Os windows_launcher.c -o NormaControl.exe -luser32. Не подменяй runtime Linux-библиотеками. README и provenance — часть поставки.
