# НормаКонтроль ОПО — Windows 1.0 RC1

Портативное приложение для Windows 10 22H2 / Windows 11 x64. Распакуйте архив целиком в доступную для записи папку и запустите **NormaControl.exe**. Python и библиотеки PDF входят в комплект; отдельная установка Python не нужна. Права администратора не требуются. При первом запуске приложение индексирует документы: дождитесь появления вкладок.

## Ваш компьютер

Профиль по фотографиям: Windows 10 Pro 22H2 x64, Intel i7-10700, 64 ГБ RAM, NVIDIA RTX A5000. Фактическая свободная видеопамять и работа CUDA на вашем ПК ещё не проверены. Запустите Diagnostics_Windows.cmd: отчёт Windows_self_test.json содержит локальную диагностику без идентификаторов устройства. Для модели и пакетов обучения понадобится дополнительное место на диске.

## Что объединено

- Реестр 33 ОПО, карточки, документы и перечни пользователя.
- Проверки ЦАУК: 330 вопросов, применимость, доказательства, отчёты.
- Ситуационные проверки: описание, фото/документы, реальные ссылки на источники, решение специалиста, PDF/HTML.
- Нормативный каталог, локальная база знаний с поиском по фрагментам, OCR при наличии Tesseract.
- Локальные роли ИИ: координатор, разработчик, интерфейс, QA и нормативный эксперт; одиночный и командный запуск.
- Подготовка проверенных примеров, LoRA-дообучение и импорт отдельной модели в Ollama.
- Единая SQLite-база, история решений и резервные копии базы вместе с вложениями.

## Документы

В комплекте 19 DOCX из предоставленного архива НД. №517 исключён. Источники автоматически разрешены для поиска как предоставленные пользователем, но НЕ отмечены юридически проверенными. Редакции взяты из самих файлов: их действительность на дату эксплуатации требует сверки. Также сохранены прежняя пользовательская копия №534 и два текста ТР ТС. Всего 22 полных текста и 46 карточек каталога; карточка не заменяет текст документа. Старые непроверенные источники не включаются в поиск автоматически.

Это корпус предоставленных материалов, а не все возможные документы для любого нефтегазового предприятия. Применимость зависит от оборудования и работ. Вкладка «Проверенные требования» предназначена для требований, проверенных специалистом и связанных с настоящим источником/фрагментом. Демонстрационные правила исходного веб-прототипа сюда не перенесены.

## Первый запуск локального ИИ

1. Установите Ollama для Windows с https://ollama.com/download/windows .
2. Запустите Install_Local_Model.cmd: он загрузит qwen2.5:14b (около 9 ГБ, нужен интернет).
3. Завершите ранее запущенный сервер Ollama, затем запустите Start_Ollama_Local.cmd. Оставьте окно сервера открытым.
4. В приложении откройте «Локальные агенты», обновите список моделей, выберите qwen2.5:14b, сохраните настройки и задайте вопрос. Адрес: http://127.0.0.1:11434.

После установки весов документы и запросы обрабатываются локально. Облачные модели и внешние адреса сервера запрещены программой. Веса Ollama не включены в архив. Реальная генерация и скорость на RTX A5000 ещё не измерены; при недостатке ресурсов можно отдельно загрузить qwen2.5:7b. Текстовая модель не анализирует фотографии автоматически.

## Обучение

Сначала используйте базу знаний: добавление документов не требует обучения весов. Для LoRA нужны проверенные пары вопрос/ответ, раздельные train/validation и локальная папка базовой Hugging Face-модели. Install_Training_Tools.cmd устанавливает дополнительные пакеты. Диагностика обучения должна подтвердить CUDA, память и зависимости. Для первого опыта выбирайте базу 7B и небольшой набор; допустимость зависит от свободной памяти. Реальное обучение и качество обученной модели в этой сборке не проверены. Сами модельные веса и CUDA-библиотеки не входят в архив или резервную копию.

## Данные и обновления

Новая база: %LOCALAPPDATA%\NormaControlOPO. Если обнаружена существующая база PromControlStage1, программа продолжает использовать её. Перед обновлением создайте резервную копию в приложении. Обновляйте папку программы целиком, оставляя пользовательские данные. Переменная PROMCONTROL_DATA_DIR задаёт иной путь для тестирования. Ошибки запуска сохраняются в %LOCALAPPDATA%\NormaControlOPO\logs.

Итоговый риск и решение фиксирует специалист. Подбор источников или ответ ИИ сам по себе не подтверждает нарушение, соответствие либо готовность ОПО к эксплуатации.

## Передача разработчику

Прочитайте docs/INTEGRATION_AUDIT_RU.md, docs/VALIDATION_WINDOWS_RC1.md и Claude_Handoff_NormaControl_OPO.md. Исходный код, тесты и исходник Windows-launcher входят в архив. Python: 3.13.16; точные версии и контрольные суммы зависимостей — в docs/WINDOWS_DEPENDENCIES.json. После установки тестовых зависимостей: runtime\python.exe -m unittest discover -s tests -v. OCR-тест требует Tesseract с eng; для OCR русского документа — rus.
