# Комплект издателя лицензий НормаКонтроль ОПО

**В комплекте закрытый ключ издателя (NormaControl_vendor_key.json).** Кто владеет этим файлом, может выпускать лицензии. Не передавайте комплект пользователям, не кладите его в папку программы и на флешки-ключи. Храните две копии на разных носителях (например, зашифрованная флешка и офлайн-хранилище). При утрате ключа новые лицензии для этой сборки выпустить нельзя — понадобится новая сборка программы с новым ключом. При утечке ключа также нужна новая сборка: прежние лицензии перестанут действовать.

## Как выдать лицензию

1. Папка комплекта должна лежать рядом с папкой программы NormaControl_OPO (так они и лежат в полном архиве). Комплекту нужен только встроенный Python программы; если программа в другом месте, скрипт спросит её папку.
2. Вставьте флешку, которая станет ключом. Подойдёт обычная USB-флешка, у которой есть серийный номер USB (у большинства фирменных флешек он есть; если нет, инструмент сообщит об этом).
3. Запустите **Issue_License.cmd**: выберите букву флешки, укажите владельца лицензии, срок (ГГГГ-ММ-ДД или пусто — бессрочно) и примечание.
4. На флешке появится файл `NormaControl.lic` (только чтение). Запись о выдаче добавляется в `issued_licenses.csv` в папке комплекта.
5. Проверьте: **Check_USB_Key.cmd**, а на компьютере пользователя — Diagnostics_Windows.cmd (раздел license).

Командная строка: `python license_tool.py issue --drive E: --licensee "ООО Пример" --expires 2027-12-31`.

## Как устроена защита

- Лицензия подписана электронной подписью Ed25519. Программа знает только открытый ключ, поэтому изменить файл (владельца, срок) или создать лицензию без закрытого ключа нельзя.
- Лицензия привязана к серийному номеру USB-устройства и серийному номеру тома флешки. Копия файла на другую флешку не действует. Форматирование флешки удаляет лицензию и меняет номер тома — выдайте лицензию заново.
- Программа проверяет ключ при запуске и каждые 15 секунд. Если флешку вынуть, появится предупреждение; через 60 секунд без ключа программа закроется (данные уже сохранены).
- Отозвать выданную лицензию дистанционно нельзя (программа не обращается к сети). Для управляемости выдавайте лицензии со сроком действия.

## Ограничения

Это программная защита обычной флешкой. Она не позволяет запустить программу без ключа обычному пользователю и не даёт подделать или скопировать лицензию на другую флешку. Специалист, способный модифицировать скомпилированный код Python или клонировать серийный номер флешки на уровне прошивки, теоретически может её обойти. Для более строгой защиты применяют аппаратные ключи с защищённым чипом (например, Guardant, Sentinel) и компиляцию в машинный код; это отдельная доработка. Исходный код программы храните в закрытом репозитории.
