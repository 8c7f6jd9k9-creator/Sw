# Проверка Windows 1.0 RC1 — 01.10.2026

## Выполнено

- 65 unittest-проверок: все прошли на Linux / Python 3.12. Полный журнал UNIT_TEST_RESULTS.txt.
- Реальный Tk GUI под Xvfb: инициализированы 8 вкладок; создание ситуации, фоновый поиск по настоящему корпусу, решение специалиста и передача текста агенту. Tk callback exceptions: 0.
- На новой базе: 33 ОПО, 330 вопросов ЦАУК, 68 источников, 23044 фрагмента. 19 источников архива НД разрешены для поиска, отметка юридической проверки не присвоена. SQLite integrity_check: ok. Повторное открытие не дублирует корпус.
- Новые тесты: ссылки на настоящий источник/фрагмент, область ОПО и сроки, отсутствие совпадения только по категории, отдельное разрешение пользовательского корпуса, атомарность CSV, ручное решение и его сброс при изменении описания или новых материалах, сохранение истории, PDF с кириллицей и фотографией, HTML escaping.
- Windows launcher скомпилирован MinGW как PE32+ GUI x64. Python 3.13.16 извлечён из официального Windows-installer; SHA-1 всех извлечённых MSI-пакетов совпадает с bootstrap-манифестом. Включены core/exe/lib/tcltk и библиотеки из Windows-wheels. Версии и SHA-256 в документах provenance/dependencies.

## Не выполнено

- Фактический запуск Windows Python, launcher и приложения на Windows: пользовательский компьютер недоступен. Попытка Wine остановлена ограничением среды `wineserver: socket: Operation not permitted`; это не проверка совместимости Windows.
- Реальная генерация Ollama, скорость и загрузка RTX A5000; модели нет в текущей среде. HTTP-контракт, ошибки, локальность и маршрутизация ролей проверены тестами с локальным/mock сервером.
- Реальное LoRA-обучение и оценка его качества: веса и GPU для обучения не предоставлены. Обработчик заданий и проверки датасетов протестированы, тренировочный процесс в тестах имитируется.
- OCR на Windows с русским Tesseract: Tesseract не включён. Реальный английский OCR проверен в Linux; отсутствие русского пакета распознавания показывается как ошибка.
- Независимая проверка действующих редакций нормативных документов и применимости к конкретным работам.

## Приёмка на компьютере пользователя

1. Распаковать весь комплект, запустить Diagnostics_Windows.cmd; проверить imports=ok и сведения о GPU/памяти.
2. Запустить NormaControl.exe, дождаться индексации, проверить 8 вкладок и 19 DOCX НД.
3. Создать ситуацию, прикрепить фото, подобрать источники, открыть оригинал, оформить решение специалиста, сохранить PDF; перезапустить и проверить данные.
4. Создать штатную резервную копию и проверить её содержание/восстановление на отдельной тестовой базе.
5. Установить Ollama и qwen2.5:14b; проверить локальный ответ с существующими ссылками, ошибки без сервера, фактическую GPU-память и приемлемую скорость. При необходимости использовать 7B.
6. До промышленной эксплуатации провести юридическую сверку и пользовательскую приёмку. RC1 обозначает кандидат сборки, а не завершённую промышленную приёмку.
