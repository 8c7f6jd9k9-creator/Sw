# Проверка исходных версий — 01.10.2026

ПОДТВЕРЖДЕНО: normkontrol-opo.zip содержит FastAPI/SQLAlchemy и React/TypeScript; сценарии ситуаций, подбор требований, эвристический риск, PDF. В seed_service.py демонстрационные требования и примеры. Исходный web прототип не является нативным Windows-приложением.

ПОДТВЕРЖДЕНО: REG-RU release 3b74969e содержит11 записей статической сборки сайта. Текст release record заявляет прохождение CI сайта; CI в текущей среде не перепроверен. В этом архиве нет backend и нативного приложения.

ПОДТВЕРЖДЕНО: NormaKontrolOPO_Xcode.zip содержит один Swift-файл и README; проекта .xcodeproj нет. Сборка macOS в данной Linux-среде не проверена.

ПОДТВЕРЖДЕНО: ПромКонтроль v0.6 содержит33 ОПО, ЦАУК, SQLite,19 документов НД без№517, OCR/RAG, Ollama и задания обучения.58 тестов пройдены в текущей среде.

РЕШЕНИЕ: сохранить проверенный нативный Tkinter+SQLite контур и адаптировать сценарий ситуационных проверок из исходников НормаКонтроль. Сайт REG-RU сохраняется как отдельный компонент и не изменяется. Демонстрационные требования не переносятся в нормативную базу. Технический эвристический риск заменяется явной оценкой специалиста; поиск источников не устанавливает нарушение автоматически. Общая база и штатный backup объединяют все контуры.

НЕ ПРОВЕРЕНО: полноценная приемка на пользовательском Windows, качество фактической локальной модели, аппаратные ресурсы для обучения. Это ограничивает утверждение о промышленной готовности.

RC2 (01.10.2026): по запросу пользователя из нормативной базы удалены служебные надписи справочных систем; исправлены ошибки Windows-поставки, найденные запуском встроенного Win64-runtime под Wine и анализом кода (docs/VALIDATION_WINDOWS_RC2.md). Архитектура (Tkinter + SQLite, локальный Ollama, LoRA) не менялась.
