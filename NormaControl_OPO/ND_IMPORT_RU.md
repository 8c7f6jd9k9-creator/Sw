# НормаКонтроль ОПО 1.0 RC2 — импорт архива НД

Архив НД.rar распакован; все 20 DOCX прошли проверку ZIP CRC. Приказ №517 исключён по указанию пользователя. В новую базу включены 19 документов из архива. Пароль архива не сохраняется в программе.

Документы архива были выгрузками из справочной правовой системы (дата выгрузки 01.10.2026). В RC2 служебные надписи системы удалены из файлов комплекта и из базы знаний: титульная плашка и логотип, «Дата сохранения», колонтитулы с адресом сайта (номера страниц оставлены), 66 редакционных примечаний системы, гиперссылки на сайт системы (текст ссылок сохранён), сведения о программе выгрузки в свойствах файла. Из пользовательской копии №534 удалены логотип и три строки сайта-распространителя. Текст норм, отметки «(в ред. …)» и списки изменяющих документов сохранены. Нумерация блоков DOCX не изменилась, поэтому прежние ссылки [Кисточник-Ффрагмент] остаются верными. Исходные SHA256 файлов записаны в ND_INVENTORY.json (original_sha256). Даты редакций ниже взяты из заголовков документов. Независимая проверка соответствия официальной действующей редакции не проводилась.

## Использование

Распакуйте приложение в новую папку. Перед обновлением сохраните штатную резервную копию старой версии. Запустите Start_Windows.cmd. При первом запуске 19 файлов автоматически добавляются к базе без сброса ранее введённых данных. Повторный запуск не создаёт дубликаты. DOCX читается без дополнительных зависимостей; библиотеки для двух ранее включённых PDF входят в комплект.

Во вкладке «База знаний / OCR» можно искать текст, открывать оригиналы и проверять сведения. Предоставленный архив НД разрешён для поиска отдельной опцией по умолчанию. После юридической проверки можно отметить источники проверенными. Файлы не получают автоматическую отметку юридической актуальности.

Приказ №517 удалён из каталога и пакета документов. Если он был импортирован предыдущей версией через нормативный каталог, связанные источники становятся неактивными и исключаются из поиска. Независимо загруженные пользователем копии, не связанные с каталогом, автоматически не идентифицируются.

Сохранены предыдущая копия ФНП №534 и два PDF ЕЭК. Старая копия №534 имеет отдельное обозначение редакции; для анализа выбирайте источник из нового архива. Сведения о датах начала/окончания действия не заполнялись автоматически.

## Обновление базы RC1

Если база создана RC1, при первом запуске RC2 программа распознаёт прежние файлы по исходному SHA256 и заменяет их очищенными копиями: идентификаторы сохранившихся фрагментов, отметки проверки и разрешения поиска не меняются; служебные фрагменты удаляются из поиска (если на такой фрагмент ссылается проверенное требование, фрагмент остаётся с пометкой «служебная надпись удалена»). Карточки каталога обновляются. Для источников, загруженных пользователем самостоятельно, служебные надписи однократно удаляются из индекса; сами файлы пользователя не изменяются. Сохранённые ранее результаты подбора в ситуациях и журнал аудита не переписываются.
