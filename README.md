# Совпадения пары

Локальный анонимный опросник на Streamlit для двух совершеннолетних партнеров. Первый партнер проходит опрос, передает устройство второму, а в финале приложение показывает только взаимные совпадения. Индивидуальные ответы, отказы и пропуски не раскрываются.

> Совпадение — только повод для разговора. Оно не является автоматическим согласием на действие. Перед любым экспериментом требуется отдельное явное согласие всех совершеннолетних участников.

## Что входит в проект

- `app.py` — интерфейс Streamlit и сценарий двух последовательных прохождений;
- `questions.py` — редактируемый каталог вопросов;
- `logic.py` — изолированная логика сравнения;
- `PRIVACY.md` — ограничения модели приватности;
- `tests/` — тесты, подтверждающие, что показываются только взаимные совпадения;
- `.github/workflows/tests.yml` — автоматическая проверка в GitHub Actions.

## Локальный запуск

Нужен Python 3.10 или новее.

### macOS или Linux

```bash
./run_local.sh
```

### Windows

```bat
run_local.bat
```

### Универсальный способ

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Обычно приложение откроется по локальному адресу `http://localhost:8501`.

2. Войдите в Streamlit Community Cloud через GitHub.
3. Создайте новое приложение и выберите репозиторий.
4. В качестве entrypoint укажите `app.py`.

Файл `requirements.txt` уже лежит в корне проекта. Внешние пакеты, кроме Streamlit, приложению не нужны.

## Приватность

Приложение не использует базу данных и не записывает ответы в файлы. Ответы первого партнера временно находятся в памяти текущей Streamlit-сессии и удаляются после сравнения. Видимые результаты содержат только совпадения.

При публикации в интернете данные текущей сессии всё равно обрабатываются удаленным сервером. Это не криптографически анонимная система. Для наиболее приватного использования запускайте приложение локально на доверенном компьютере. Подробнее: [`PRIVACY.md`](PRIVACY.md).

## Настройка вопросов

Откройте `questions.py` и отредактируйте список `QUESTIONS`. Каждый пункт должен иметь уникальный `id`, категорию `category` и текст `text`.
